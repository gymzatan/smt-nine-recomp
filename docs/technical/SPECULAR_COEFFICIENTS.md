# Fixed specular coefficient consumers

The game producer sub_002FC0C0 uploads six front coefficients at method 0x09E0 and six back coefficients at 0x1E28. It calls the original sub_002F6910 on its material parameter and that parameter multiplied by the original constant 0.5. Those are standing coefficient products; the renderer does not reconstruct an exponent or introduce another material.

The existing native fixed shader and software fixed vertex function use A/B/C for a directional light with LOCAL_EYE disabled: the existing rational expression consumes the supplied infinite half-vector. For LOCAL_EYE or positional/spot lights, H is the existing unnormalized eye-plus-light vector, s=N dot H, ss=s*s and hd=H dot H. The second expression is (ss+hd*D)/(ss*E+hd*F), subject to the same established sign and denominator clamps. Front and back use their independent existing six-value state and the reversed normal on the back face. The native fixed constant buffer carries the existing second products in two appended vectors; original prefix layouts remain intact.

The mathematical branch comes from the primary [Celsius hardware model](https://github.com/envytools/envytools/blob/master/nvhw/pgraph_celsius_xfrm.c), function pgraph_celsius_lt_full. Its named coefficient identities map to NV20 in the primary [XF context table](https://envytools.readthedocs.io/en/latest/hw/graph/xf/ctx.html#ltc); the original Kelvin method model confirms the front/back slots. The [XF mode documentation](https://envytools.readthedocs.io/en/latest/hw/graph/xf/mode.html#xfmode-kelvin-rankine) identifies the relevant viewer and light modes. Applying the same named function to NV20 is a source-supported cross-generation inference, not a new silicon measurement.

The non-local eye vector remains the existing zero vector from the accepted xemu-derived NV2A path. Celsius LTCTX[0x28] has no mapped NV20 counterpart in the context table, so it is not relabeled as NV20 C56. The established local-eye C56 homogeneous-position calculation is preserved.

The absolute-output fixture uses N=(0,0,1), unit eye/light vectors with components (sqrt(3)/2,0,0.5), and A/B/C=(0,0,1). The directional non-local path returns 0.5; D/E/F=(0,0,1) returns 0.25 in the second branch. Independent D, E and F changes produce distinguishable values. Both faces, all three light modes, viewer modes and a restored back state reach real rendered pixels in software and four native backend configurations. The preserved earlier shader produces ff7f7f7f where the second branch requires ff404040. The prior two-sided fixture now supplies D/E/F=(0,0,1) as well as A/B/C=(0,0,1), because its local/spot inputs exercise the second triplet; its front/back comparison remains unchanged.
