# 操作说明

直接双击根目录的 `smt9_recomp.exe` 游玩，双击 `Config.exe` 调整设置。在 Config 中点击“操作说明”可查看中、日、英三语说明；内容较长时可滚动阅读。

在 Config 中点击“按键设置”可分别修改键盘和 XInput 手柄映射；选择或捕获输入，可设为“不绑定”或“恢复默认”。点击“应用”后在主窗口“保存”，下次启动生效，程序更新会保留设置。F1～F5、F8、F9 为保留快捷键。

下表为默认键位，“游戏按键”对应初代 Xbox 手柄按钮，具体游戏功能以当前画面提示为准。十字键与左摇杆是两组不同的输入；键盘标点按美式键盘键帽标注。

| 十字键下 | 十字键下 | ↓ |
| 十字键左 | 十字键左 | ← |
| 十字键右 | 十字键右 | → |
| 左摇杆上 | 左摇杆上 | W |
| 左摇杆下 | 左摇杆下 | S |
| 左摇杆左 | 左摇杆左 | A |
| 左摇杆右 | 左摇杆右 | D |
| 右摇杆上 | 右摇杆上 | I |
| 右摇杆下 | 右摇杆下 | K |
| 右摇杆左 | 右摇杆左 | J |
| 右摇杆右 | 右摇杆右 | L |
| 左摇杆按下（L3） | 按下左摇杆 | 数字 1 |
| 右摇杆按下（R3） | 按下右摇杆 | 数字 2 |
| A | A | `.`（句号） |
| B | B | `/`（斜杠） |
| X | X | `;`（分号） |
| Y | Y | `'`（单引号） |
| L | LB | Q |

| 黑键（Black） | RT | `]`（右方括号） |
| Start | Start / Menu | 右 Shift |
| Back | Back / View | Backspace（退格） |

LT/RT 保留按压程度，键盘按钮按满按处理。键盘默认启用，与第一只手柄的输入合并。游戏窗口位于前台时才接收键盘和手柄输入。

| 窗口操作／快捷键 | 功能 |
| --- | --- |
| 双击游戏画面 | 切换无边框全屏；再次双击恢复窗口位置和尺寸 |
| F8 | 截图，BMP 保存在程序目录的 `runtime/Screenshots`；按游戏比例和渲染高度保存，不含标题栏 |
| F9 | 暂停／继续游戏、计时和声音；暂停时仍可截图与切换全屏 |
| 左 Shift + F1～F5 | 分别保存即时档 1～5 |
| F1～F5 | 分别读取即时档 1～5 |
| 关闭游戏窗口 | 退出游戏，包括暂停状态 |

使用即时档前先按 F9 解除暂停。即时档必须匹配保存时的游戏程序与游戏镜像；更新程序前请保留普通存档。暂停和即时保存需要游戏到达现有的安全边界；请求失败时会在窗口中提示，该次操作不会生成有效即时档。

Config 提供 640×480、960×720、1280×720、1280×960、1600×900、1920×1080、2560×1440、3840×2160 及自定义窗口尺寸。勾选“固定窗口宽高比”后，拖动边角保持所选尺寸的客户区比例。游戏画面比例独立于窗口尺寸，多余区域留黑。保存后下次启动游戏生效。

Config 界面语言与游戏语言独立。游戏存档、配置、语言包与截图保存在本地。
